# ASP.NET Core Coding Sandbox

A C# learning project exploring an ASP.NET Core endpoint, Entity Framework Core entities and repository/test fixtures.

## Status

Incomplete sandbox. The card-holder repository method is not implemented and the test projects include placeholders. This repository is not a production payment service or a finished reference architecture.

Open `challengeApp.sln` in a .NET IDE to inspect the projects and their target frameworks. Build outputs currently present in the repository are historical artifacts and should not be relied on as release binaries.

The next useful work is to complete the repository behavior, replace placeholder tests with behavioral assertions, remove generated build outputs from tracking, and document a reproducible run path.
